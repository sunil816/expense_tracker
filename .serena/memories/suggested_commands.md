# Suggested Commands

Run from repository root (`C:\learn\Learn\expense_tracker`):

- Build solution: `dotnet build ExpenseTracker/ExpenseTracker.slnx`
- Run all tests: `dotnet test ExpenseTracker/ExpenseTracker.slnx`
- Run API: `dotnet run --project ExpenseTracker/ExpenseTracker/ExpenseTracker.csproj`
- Verify qpdf: `qpdf --version`
- Check Serena memory references after memory changes: `serena memories check`
